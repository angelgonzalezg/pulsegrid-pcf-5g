# pulsegrid-pcf-5g
PulseGrid PCF 5G Lab | Distributed Go policy engine for 5G session control (3GPP Rel-17) utilizing an event-driven architecture, Redis/Valkey cache-aside, and PostgreSQL transactional outbox pattern.
